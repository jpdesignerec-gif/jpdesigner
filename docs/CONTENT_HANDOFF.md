# Entrega de contenido

Completar este archivo o trasladar cada dato al admin antes del lanzamiento. No marcar como publicado hasta que el contenido sea real y revisado.

## Servicios

Para cada servicio confirmar:

- Nombre, slug y descripción comercial.
- Precio base o texto “desde”, moneda e impuestos si aplican.
- Tiempo de entrega real.
- Requisitos que debe entregar el cliente.
- Entregables y formatos.
- Revisiones incluidas y costo de adicionales.
- Qué no está incluido.
- Preguntas del cotizador, tipo de respuesta, opciones y obligatoriedad.

## Planes

Confirmar precio, alcance, características, formatos, revisiones, tiempos, exclusiones, plan recomendado y llamada a la acción.

## Portfolio

Cada proyecto necesita título, resumen, cliente autorizado, año, categoría, tags, portada, galería, caso de estudio, alt text, derechos de uso y estado editorial.

## Confianza y legal

Los testimonios deben tener autorización verificable. Revisar privacidad, tratamiento de datos, adjuntos, cookies, contacto, cancelaciones y condiciones de pago con la información legal real del negocio.
